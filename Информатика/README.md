## Статус и изменения на 2027 год

Проверено **23 октября 2026 года** по опубликованным ФИПИ проектам демоверсии, спецификации и кодификатора. На документах сохранена отметка «ПРОЕКТ».

- Сохраняются **27 заданий**, максимум **29 первичных баллов**, время — **235 минут**. №1–25 дают по 1 баллу, №26–27 — по 2.
- **№10**: вместо информационного поиска в текстовом процессоре проверяется использование маски подсети.
- **№13**: вместо маски подсети — анализ исполнения алгоритма, включая подсчёт программ исполнителя.
- **№23**: вместо прежней задачи об исполнителе — алгоритмы на графах: оптимальные пути и число путей в ориентированном ациклическом графе.
- **№27**: ответ содержит **одну строку из двух чисел**. В демоверсии дан один файл с признаками объектов и кластеризацией по вычисляемой характеристике.

В №12 актуальная демоверсия использует исполнителя с лентой, головкой и состояниями. В №27 способ вычисления признака, метрика, центр кластера и итоговые характеристики определяются условием задачи. Подготовка охватывает весь процесс анализа данных.

Структура: **раздел = номер задания → темы → пункты**. Программные приёмы удобно отрабатывать на Python; при использовании другого разрешённого языка сохраняются те же алгоритмы. Для электронных таблиц следует освоить доступный на экзамене редактор и его формулы.
