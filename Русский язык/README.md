## Статус и сопоставление с 2026 годом

Проверено **23 октября 2026 года** по опубликованным ФИПИ проектам демоверсии, спецификации и кодификатора. В документах сохранена отметка «ПРОЕКТ». В официальном перечне существенных изменений на 2027 год для русского языка указано отсутствие изменений.

- Работа содержит **27 заданий**, максимум **50 первичных баллов**, время — **210 минут**.
- В первой части **26 заданий** с максимумом **28 баллов**. №8 и №22 дают по **2 балла**, остальные задания первой части — по 1.
- №27 — сочинение с максимумом **22 балла** по критериям К1–К10.
- Актуальная последовательность: **№22 — средства выразительности; №23 — содержание текста; №24 — типы речи и смысловая организация; №25 — лексика; №26 — связь предложений**.
- Сочинение должно содержать **не менее 150 слов**. В актуальной демоверсии работа на 149 слов и меньше оценивается нулём по всем критериям.

Структура: **раздел = номер задания → темы → пункты**. Словарные материалы, формулировки заданий и критерии следует сверять с актуальными документами ФИПИ. Программа раскрывает необходимые правила и способы анализа, а конкретные языковые примеры в вариантах могут различаться.
